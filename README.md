# Project Kaida Website

Welcome to the official repository for the **Project Kaida** website, a dedicated portal for our private "forever vanilla" Minecraft survival server.

## 🌟 Website Features

This website serves as a hub for the community, archiving our history and showcasing our world.

### 🏠 Home Page
-   **Server Status & Info:** General information about the server hosting and philosophy.
-   **Events Timeline:** A record of major server events like the *One Year Anniversary* and *Resurrection Event*, complete with video perspectives.
-   **Farms Database:** A list of public farms (Gold, Froglight, Wither Skeleton, etc.) with coordinates, production rates, and types.
-   **Nether Networks:** Explanations of transportation infrastructure, including the Nether Highway and Nether Road Network.

### 🏰 Main Bases
A gallery showcasing the unique bases built by our players, including:
-   **Brexit Giza** by AaroTron9000
-   **Klein-Honningstal** by AlbertAllrad
-   **The Mines™** by AndroidJackBob
-   **Barad-dûr** by ZakZNinja
-   ...and many more!

### 🗺️ Interactive Maps
We provide high-resolution isometric renders of our world to track progress over time:
-   **Year 0 Map** (Day)
-   **Year 1 Map** (Day & Night)
-   **Year 2 Map** (Day & Night)

## 🛠️ Tech Stack

This website is built using standard web technologies:

-   **HTML5**
-   **CSS3**
-   **JavaScript** (Vanilla)
-   **[Leaflet.js](https://leafletjs.com/)** - For interactive map rendering.
-   **[Minecraft Overviewer](https://github.com/overviewer/Minecraft-Overviewer)** - Used to generate the isometric map tiles.
-   **[MCA Selector](https://github.com/Querz/mcaselector)** - Used for map chunk editing and preparation.
